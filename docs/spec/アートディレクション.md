### 塗装とマーキング
パーツのマテリアルは次の 3 種類（Blender のスロット名 `Mat_Main` / `Mat_Sub` / `Mat_Light`）。カスタマイズでパーツごとに色と材質を変える単位になる（#230）。

| 種類 | 用途 |
|---|---|
| Main | パーツの主な面 |
| Sub | ディテール・パネルライン・関節など、Main と色を分けたい面 |
| Light | 光らせたい箇所（カメラアイ・バイザー・ライトなど）。既定で発光する。光らせる箇所が無いパーツには付けない |

ブースターのノズル（`Mat_Thruster`）は 3 種類とは別で、色はブースターの設定（炎の色）で決まる。
