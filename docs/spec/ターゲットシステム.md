# # ターゲットUI
射撃目標となるターゲット周辺に以下のUIを表示させる
* 設定したターゲットとカメラまでの距離  
* 左右の武器のロック状態を左右のImageで表示する（ロックしていなければ非表示、一次ロックは通常の色、二次ロックは別の色）
* ターゲットの残りHPを数値で表示
# ロックの段階
ロックサークル内でいちばん近い目標をロックし、射撃の目標にする。ロックは2段階あり、左右の武器（とサブ武器）で別々に判定する
* 一次ロック：目標をロックした状態。目標の現在位置に当たるように撃つ（弾が自機の速度を引き継ぐ分は補正する）
* 二次ロック：同じ目標を一次ロックし続けて、銃ごとに決まる時間（銃のマスタ `GunSettings` の `secondaryLockTime`）が経った状態。目標の速度も使って偏差射撃する
* 目標が変わると、二次ロックまでの時間は数え直しになる
* プレイヤー・NPC・敵ユニットは同じロックと偏差の計算を使う。NPC は目標を見つけた時点で一次ロックになる
## 偏差射撃
* 弾の初速は「照準方向 × 弾速 + 自機の速度」
* 自機と目標の相対位置・相対速度から、弾が当たる時間を求めて照準点を決める。目標は発射した瞬間の速度のまま等速で動くと仮定し、加速度と重力は考えない
* 弾が目標に追いつけないときは、目標の現在位置へ撃つ
* 加速・減速・旋回する目標には外れやすくなる。これは仕様で、緩急をつけた移動は（プレイヤーにとっても）有効な回避手段になる
* 目標の速度は、Rigidbody があれば `linearVelocity`、なければ前フレームとの位置の差分から求める
