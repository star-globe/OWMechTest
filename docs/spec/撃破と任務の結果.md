# 機体の撃破
プレイヤーの機体と NPC の機体（NPCPlayer）は同じ処理をする
1. AP が 0 になった時点で撃破とし、入力（NPC は AI の行動）を止める。NPC は部隊から外れる
2. 撃破の演出（爆発）が終わったら機体の表示を消す。撃破した後は被弾しない

# 任務の結果
- 成功: 目標を撃破したら Result へ遷移する
- 失敗: プレイヤーの機体が撃破されたら、撃破の演出の後に Result へ遷移する
- 最初に決まった結果を優先する（自機の撃破の演出中に目標を壊しても失敗のまま）
- Result 画面では、失敗のとき「Failed」と表示する（表示の細かい仕様は別途決める）
