# 移動操作
## エネルギー
自機の操作にはエネルギーを必要とし、アクションを行う度に消費し時間によって回復する。
### 回復力
エネルギーは毎秒、回復力の分だけ回復する。
回復力 ＝ ジェネレーターの総出力 − 装備した各パーツの常時消費の合計
- 最大エネルギーは、ジェネレーターの総容量で決まる
- 回復力は機体の状態でも変わる。ブーストが ON の間は（地上でも空中でも）、ブースターの常時消費が加わって下がる
- 回復力は、どの状態でも必ず 0 より大きい（[[基本仕様]] の「機体のカスタマイズ」）
### オーバーヒート
エネルギーを消費する行動は、残量が 0 以上なら実行できる。実行して残量がマイナスに達したら、残量を 0 としてオーバーヒートする（ちょうど 0 ならオーバーヒートしない）
- オーバーヒート中は、オーバーヒート時間の間、エネルギーを使う行動ができない。ハイパーブーストとグライド中の上昇はその場で止まる。原因になったジャンプ・クイックブーストは最後まで出る
- 解除時の残量を復帰エネルギーと呼び、最大エネルギーに対する割合で決める。オーバーヒート中は通常の回復をせず、残量が 0 から復帰エネルギーまで一定の速さで増える
- オーバーヒート時間と復帰エネルギーは、ジェネレーターで決まる（暫定の初期値: 3 秒、30%）
- ブーストの ON / OFF と、その効果（移動速度・落下の軽減）はオーバーヒート中も変わらない
- オーバーヒート中は、エネルギーゲージ全体が赤く明滅する
## カメラと回転
三人称視点で操作。コントローラによる操作を前提とし、右スティック操作でカメラと自機の回転をコントロールする。
### 遮蔽物への対応
カメラが床・壁・障害物にめり込まないよう、位置を調整する。
- 機体の中心から、予定しているカメラ位置への直線で判定する。遮蔽物に当たったら、当たった点の少し手前にカメラを置く
- 判定の始点は機体の中心の高さ（注視点の基準）とし、カメラの大きさ程度の球で判定する。カメラは当たった点からその分だけ手前に置く
- 判定の対象は地形と障害物だけにする。自機・弾・トリガーには反応しない（[[レイヤー管理]]）
- 他の機体・ユニット（戦車・ドローンなど）には反応しない。動く相手で視点が揺れるのを避けるため
- 寄せるときは遅れずにすぐ寄せる。遮蔽がなくなったら、通常の追従で元の距離へ滑らかに戻す
## ジャンプ
エネルギーを消費してジャンプする。地面だけでなく、壁に接地している状態でもジャンプできる（ただし角度の制限がある）
## ブーストのオンオフ
機体はブースト状態のオンオフ切替によって挙動が変化する。基本的な移動スピードが変化し、落下速度を軽減させる。
切り替えにエネルギーは消費せず、残量も関係しない。ON の間は回復力が下がる。
- ブースト ON の移動スピードは、ブースターのブースト出力で決まる
- ブースト出力は、通常の移動スピードに掛ける倍率で表す（暫定。本体のスピードとの関係は #218 で決める）
## クイックブースト
エネルギーを消費して、入力した方向へ短い時間だけすばやく移動する
- 出力（移動の速さ）、1 回の消費エネルギー、噴射時間は、ブースターで決まる
## ハイパーブースト
ブースト ON の間に使える。入力した方向（入力が無ければ前方）へ高速で移動し続け、その間エネルギーを消費し続ける
- ジャンプしたとき、入力をやめたとき、開始時と逆向きに入力したときに終わる
- 出力（移動の速さ）と、1 秒あたりの消費エネルギーは、ブースターで決まる
## 機体のモーション
### 待機
肘と膝を軽く曲げ（関節の角度で 150 度程度）、正面から見て腕と脚が八の字になる姿勢にする。歩行・ブースト・射撃の構えなど、ほかの行動へ自然につなげやすい準備姿勢とする。カスタマイズ画面のプレビューでも同じ待機モーションを使う
### 歩行
上半身はカメラの方向を向く。下半身（脚部）は、カメラ正面から見た移動方向の角度で、向きと歩き方を切り替える

| 移動方向の角度（カメラ正面から） | 下半身の向き | 歩き方 |
|---|---|---|
| 80 度未満 | 移動方向 | 前歩き |
| 80〜100 度 | カメラ方向のまま | カニ歩き（横歩き） |
| 100 度以上 | 移動方向の反対 | 後ろ歩き |

- 境界の角度の付近で、歩き方や向きがちらつかないようにする
- 歩行はゆっくりした周期で動かす（暫定: 改修前の 1.5 倍程度）
### ブースト移動
ブースト ON で移動しているときは歩行モーションを使わず、待機の姿勢を移動方向へ傾ける。傾きは移動速度に応じて大きくし、止まったときや向きを変えたときは滑らかに戻す。上半身がカメラの方向を向くのは歩行と同じ
# 攻撃操作
## 射撃操作
右射撃・左射撃・サブ射撃の 3 つのボタンで、それぞれのスロットの武器を撃つ（[[武装]]）
## ロックオンサークルと射撃
画面内にサークルを表示させ、サークル内でいちばん近い敵をロックして、その敵に向けて射撃する。ロックしている敵がいなければ正面へ射撃する。
ロックは一次ロック（現在位置を狙う）と二次ロック（一定時間ロックし続けると偏差射撃）の2段階がある（詳細は [[ターゲットシステム]]）
