# 移動操作
## エネルギー
自機の操作にはエネルギーを必要とし、アクションを行う度に消費し時間によって回復する。
## カメラと回転
三人称視点で操作。コントローラによる操作を前提とし、右スティック操作でカメラと自機の回転をコントロールする。
## ジャンプ
エネルギーを消費してジャンプする。地面だけでなく、壁に接地している状態でもジャンプできる（ただし角度の制限がある）
## ブーストのオンオフ
機体はブースト状態のオンオフ切替によって挙動が変化する。基本的な移動スピードが変化し、落下速度を軽減させる。
# 攻撃操作
## 射撃操作
コントローラに設定した射撃ボタンで一定方向に射撃する
## ロックオンサークルと射撃
画面内にサークルを表示させ、サークル内の敵に射撃が当たるように射撃方向を制御する
# パラメーター管理
各種のパラメーターの設定はScriptableObjectで設定する（見づらいのでスプレッドシートなどで管理できると望ましい）
