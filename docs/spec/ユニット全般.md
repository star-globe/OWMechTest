# 大まかな定義
ユニットとは特定のロジックに従って動く固定装備キャラクター全般のことである
対比としてプレイヤーと同じカスタマイズ可能な装備を備えつつも特定のロジックで動くキャラクターはNPCPlayerと呼称する
# 特徴
Unitには以下のような特徴がある
* APとMAXAPがある
* タイプごとのモデルが存在する
* 攻撃手段を持つ（持たないものも存在する）：発射する弾と発射間隔が定義されている
* ユニットごとに移動方法が異なり（地上移動タイプ、空中移動タイプ、固定タイプ）、移動速度、回転速度に関するパラメーターを持つ
# ユニットのタイプ
現在想定しているユニットは以下のタイプがあり、必要な設定が異なる
1. 固定砲台：発射間隔、弾ID、俯角迎角、砲塔回転速度（X軸Y軸）
2. ドローン：発射間隔、弾ID、水平移動速度、垂直移動速度、回転速度
3. 戦車：発射間隔、弾ID、俯角迎角、砲塔回転速度（X軸Y軸）、直進速度、旋回速度（Y軸）

ユニットタイプの定義は随時更新予定

# 移動パターン
移動するユニット（戦車・ドローン）は、マスタ（UnitMovePatternSettings）で決めたパターンで動く。ランダムな動きはしない
1. 等速の円運動：中心（スポーン位置からのオフセット）、半径、速さ、回転方向。面は水平面か縦の面（空中のみ）
2. 停止と直進の繰り返し：停止 → 加速 → 最高速度で直進 → 減速 → 停止。直進するたびに決まった角度だけ曲がる（180 度で往復、90 度で四角形）

UnitSettings の ID を変えるだけで、同じモデルで別のパターンの敵を置ける
# 射撃
ユニットもプレイヤーと同じ攻撃ロジック（一次ロック・二次ロックと偏差射撃）を使う。二次ロックになるまでの時間はユニットのパラメーターで持つ

# スケールの基準
- プレイヤー機体（人型兵器）の全高は 8 m を基準とする
- 他のユニット・地形・配置物の大きさは、この基準との比率で決める
- フィールドの配置物は、機体が今の約 1/3 だったころ（#90 以前）の配置を 3 倍にした比率を基準とする
- 大きさの目安（全高 / 機体比）: 戦車 2.5 m / 0.31、砲台 7 m / 0.9、建物（BuildObject）7.2 m / 0.9、遮蔽物の柱 7.6〜50 m
- NavMesh は機体用のエージェント「Mech」（半径 1.4 m、高さ 8 m）でベイクする
